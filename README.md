# 🕷️ HH.ru Vacancy Parser

Автоматический парсер вакансий с сайта HeadHunter с фильтрацией по опыту, локации и формату работы. Найденные вакансии отправляются в личные сообщения ВКонтакте.

Главная особенность: скрипт **полностью автоматизирован** (запускается ежедневно в 9:00 по Челябинску через GitHub Actions) и **сохраняет историю в облачной базе данных (Neon.tech)**, что на 100% исключает отправку дубликатов.

Данный парсер написан исключительно для себя, но при желании можно масштабировать.

## ✨ Возможности

- 🔍 Поиск вакансий по ключевому слову в названии
- 💼 Фильтрация по опыту работы (без опыта / 1–3 года)
- 📍 Фильтрация по городу или удалённый формат работы
- 📝 Парсинг описания обязанностей прямо из карточки на странице поиска (высокая скорость)
- 📱 Автоматическая отправка уведомлений в VK
- 🗄️ **Защита от дубликатов:** проверка URL вакансии по облачной PostgreSQL перед отправкой
- ⏰ **Автоматизация:** ежедневный запуск без участия человека (GitHub Actions)
- 🐳 Поддержка локального запуска через Docker (для разработки)

## 🛠 Технологии

- **Python 3.11**
- **Selenium** — автоматизация браузера (Chrome)
- **BeautifulSoup4 + lxml** — быстрый парсинг HTML
- **Neon.tech (PostgreSQL)** — бесплатная облачная база данных для хранения истории
- **psycopg2-binary** — драйвер для работы с PostgreSQL
- **vk_api** — отправка сообщений в ВКонтакте
- **GitHub Actions** — планировщик и CI/CD

## 🚀 Настройка автоматического запуска (Рекомендуется)

Этот способ не требует наличия собственного сервера или постоянно включенного компьютера. Всё работает в облаке GitHub бесплатно.

### Шаг 1: Настройка облачной базы данных (Neon)
1. Зарегистрируйтесь на [neon.tech](https://neon.tech) (можно через GitHub).
2. Создайте новый проект и скопируйте **Connection String** (строка подключения).
   *Пример: `postgresql://user:password@ep-xxx.aws.neon.tech/dbname?sslmode=require`*

### Шаг 2: Добавление секретов в GitHub
1. Перейдите в настройки репозитория: **Settings** → **Secrets and variables** → **Actions**.
2. Нажмите **New repository secret** и добавьте четыре переменные:
   - `VK_TOKEN`: Ваш токен сообщества или пользователя VK.
   - `VK_USER_ID`: Ваш числовой ID ВКонтакте.
   - `DATABASE_URL`: Скопированная строка подключения от Neon.tech.
   - 'HH_COOKIES': Ваши куки с авторизованной страницы на HH в json формате.

### Шаг 3: Готово!
Парсер автоматически запускается каждый день в **04:00 UTC (09:00 по Челябинску)**. 
Чтобы проверить работу прямо сейчас, перейдите во вкладку **Actions** в репозитории, выберите **Daily HH Parser** и нажмите кнопку **Run workflow**.

## Вариант B: Установка и запуск без Docker

### 1. Клонируйте репозиторий
```bash
git clone <https://github.com/GoodWinee/HH.ru-Vacancies-Parser->
```

### 2. Создайте виртуальное окружение
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
```

### 3. Установите зависимости
```bash
pip install -r requirements.txt
```

### 4. Настройте базу данных и окружение
Установите и запустите локальный сервер PostgreSQL.
Создайте файл .env (как показано выше), указав DB_HOST=localhost.
Скрипт автоматически создаст нужную таблицу при первом запуске.

### 5. Запустите парсер
```bash
python main.py
```

## ⚙️ Настройка поиска

Откройте файл constants.py и измените параметры под ваши задачи:
```bash
# URL поиска на hh.ru (убедитесь, что в нём нет временного параметра search_session_id)
SEARCH_URL = "https://hh.ru/search/vacancy?area=144&text=python&enable_snippets=true"
# Ключевое слово для дополнительной фильтрации в названии
KEYWORD = "python"
# Город для фильтрации (проверка по вхождению подстроки)
LOCATION = "москва"
# Количество страниц для парсинга за один сеанс
MAX_SEARCH_PAGES = 4
```
## 🚀 Запуск
```bash
python main.py
```
## 🛡️ Как работает защита от дубликатов?
Скрипт находит подходящую вакансию на странице поиска.
Делает запрос к базе данных: SELECT 1 FROM processed_vacancies WHERE url = %s.
Если ссылка уже есть в базе → вакансия пропускается ⏭️ Пропуск (уже в базе).
Если ссылки нет → вакансия отправляется в VK, а её URL сохраняется в таблицу processed_vacancies.
