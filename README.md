# 🕷️ HH.ru Vacancy Parser

Автоматический парсер вакансий с сайта HeadHunter с фильтрацией по опыту, локации и формату работы. Найденные вакансии отправляются в личные сообщения ВКонтакте.
Данный парсер написан исключительно под свои потребности.

## ✨ Возможности

- Поиск вакансий по ключевому слову в названии
- Фильтрация по опыту работы (без опыта / 1–3 года)
- Фильтрация по городу или удалённый формат работы
- Парсинг описания обязанностей прямо из карточки вакансии
- Автоматическая отправка уведомлений в VK
- Поддержка пагинации (парсинг нескольких страниц поиска)
- Работа в headless-режиме (без открытия окна браузера)

## 🛠 Технологии

- **Python 3.10+**
- **Selenium** — автоматизация браузера
- **BeautifulSoup4** — парсинг HTML
- **vk_api** — отправка сообщений в ВКонтакте
- **python-dotenv** — работа с переменными окружения

## 🐳 Запуск через Docker (Рекомендуется)
### 1. Убедись, что файл `.env` заполнен
### 2. Собери и запусти контейнер
```bash
docker-compose up --build
```
## 📦 Установка без Docker

### 1. Клонируйте репозиторий

```bash
git clone <url-вашего-репозитория>
cd hh_parser
```
### 2. Создайте виртуальное окружение
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
```
### 3. Установите зависимости
```bash
pip install -r requirements.txt
```
### 4. Установите ChromeDriver
```bash
pip install webdriver-manager
# Или скачайте вручную с официального сайта.
```
## ⚙️ Настройка
```bash
# Создайте файл .env в корне проекта:
VK_TOKEN=ваш_token_сообщества_или_пользователя
VK_USER_ID=ваш_id_в_vk
```
## 🚀 Запуск
```bash
python main.py
```
