# 🕷️ HH.ru Vacancy Parser

Автоматический парсер вакансий с сайта HeadHunter с фильтрацией по опыту, локации и формату работы. Найденные вакансии отправляются в личные сообщения ВКонтакте. 

Главная особенность: скрипт **сохраняет историю обработанных вакансий в PostgreSQL**, что полностью исключает отправку дубликатов при повторных запусках.

Данный парсер написан под конкретные потребности, но легко масштабируется.

## ✨ Возможности

- 🔍 Поиск вакансий по ключевому слову в названии
- 💼 Фильтрация по опыту работы (без опыта / 1–3 года)
- 📍 Фильтрация по городу или удалённый формат работы
- 📝 Парсинг описания обязанностей прямо из карточки вакансии на странице поиска (без перехода по ссылкам, что ускоряет работу)
- 📱 Автоматическая отправка уведомлений в VK
- 🗄️ **Защита от дубликатов:** проверка URL вакансии по базе данных перед отправкой
- 📄 Поддержка пагинации (парсинг нескольких страниц поиска)
- 🐳 Полная поддержка **Docker** (развёртывание в один клик вместе с базой данных)

## 🛠 Технологии

- **Python 3.10+**
- **Selenium** — автоматизация браузера (Chrome)
- **BeautifulSoup4 + lxml** — быстрый парсинг HTML
- **PostgreSQL + psycopg2-binary** — хранение истории обработанных ссылок
- **vk_api** — отправка сообщений в ВКонтакте
- **python-dotenv** — безопасная работа с переменными окружения
- **Docker & Docker Compose** — контейнеризация

## 🐳 Запуск через Docker (Рекомендуется)

Это самый простой способ, так как он автоматически поднимает и парсер, и базу данных PostgreSQL.

### 1. Настройте переменные окружения
Создайте файл `.env` в корне проекта на основе `.env.example` и заполните его:
```bash
# VK API
VK_TOKEN=ваш_токен_сообщества_или_пользователя
VK_USER_ID=ваш_id_в_vk

# PostgreSQL
POSTGRES_DB=parser
POSTGRES_USER=parser_user
POSTGRES_PASSWORD=parser_password
DB_HOST=db
DB_PORT=5432
```

### 2. Собери и запусти контейнер
```bash
docker-compose up --build
```
## 📦 Установка и запуск без Docker

### 1. Клонируйте репозиторий

```bash
git clone <https://github.com/GoodWinee/HH.ru-Vacancies-Parser->
```
### 2. Создайте виртуальное окружение
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
```
### 3. Установите зависимости
```bash
pip install -r requirements.txt
```
### 4. Настройте базу данных и окружение

Установите и запустите локальный сервер PostgreSQL.
Создайте файл .env (как показано выше), указав DB_HOST=localhost.
Скрипт автоматически создаст нужную таблицу при первом запуске.

### 5. Запустите парсер
```bash
python main.py
```

## ⚙️ Настройка поиска

Откройте файл constants.py и измените параметры под ваши задачи:
```bash
# URL поиска на hh.ru (убедитесь, что в нём нет временного параметра search_session_id)
SEARCH_URL = "https://hh.ru/search/vacancy?area=144&text=python&enable_snippets=true"
# Ключевое слово для дополнительной фильтрации в названии
KEYWORD = "python"
# Город для фильтрации (проверка по вхождению подстроки)
LOCATION = "москва"
# Количество страниц для парсинга за один сеанс
MAX_SEARCH_PAGES = 4
```

```bash
python main.py
```
